# 公开使用手册

公网版同时提供网页手册：`{公网体验链接}/guide`。部署完成后把占位符替换为真实地址。

## 3 分钟评委路径

1. 打开公网链接。首页已经选中“白虎岭”，点“进入白虎岭全景”。
2. 在 360°场景拖动环视，点击白色文化热点；若想快速看完整内容，点左下角“原著证据导览 · 11 条”。
3. 在展签中切换“原文 / 简释 / English”，查看第二十七回的原始文本行号。
4. 读完 9 条核心线索后，点右下角“进入真相时间线”。
5. 手动排序并匹配证据，或点“加载演示答案”后再点“校验时间线”。演示答案仍通过正常校验逻辑，不会直接解锁。
6. 点“查看奖励”，查看白虎岭章节奖励和下一节点预览。

## Gemini 多模态导览

打开任意展签，在“让 Gemini 看见画面，也读懂原文”区域输入问题。浏览器只提交热点 ID、当前语言和问题；服务端从白名单内容中读取对应原文与当前全景，再请求 Gemini。若公网部署未配置 Key，页面会明确说明 AI 导览是可选功能，其余体验不受影响。

## 兼容与回退

- 推荐最新版 Chrome、Safari 或 Edge。
- 桌面端可拖动、滚轮缩放；手机端可触控拖动、双指缩放。
- WebGL 加载失败时会显示静态场景。此时仍可打开“原著证据导览”，读完展签、解锁小游戏和奖励。

## 隐私与用量

- 不要求登录，不接入行为分析。
- 探索进度只保存在当前浏览器的 `localStorage`。
- 只有主动提问时，问题和当前公开展签上下文才会发往服务端。
- API Key 不会发送到浏览器。
- AI 问题最长 400 字，并设置每来源地址每分钟 8 次的基础限流。

## 内容边界

当前完整开放《西游记》第二十七回“三打白骨精”。其他地图节点为锁定或预览状态。展签原文来自仓库保存的 Project Gutenberg eBook #23962《西遊記》，每段都带原始文本行号并由自动测试核对。
