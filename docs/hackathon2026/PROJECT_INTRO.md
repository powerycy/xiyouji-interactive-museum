# 项目介绍

## 一句话

把《西游记》第二十七回做成一座能走、能查、能推理的 360°互动博物馆；AI 只能在原著证据范围内讲解，不替原著编答案。

## 报名短介绍

《西游镜界》从一个很具体的问题出发：名著数字化常常只剩“看图听讲”，接入 AI 后又容易把流畅回答误当成可靠内容。我们选择先做深《西游记》第二十七回，把 11 条可回查原文行号的证据放进 4 个白虎岭 360°场景。观众可以拖动环视寻找热点，也可以按故事顺序使用证据导览；读完 9 条核心线索后，通过时间线与证据匹配理解“三打白骨精”为什么最终变成师徒决裂，再领取章节奖励。

Gemini 是可选的多模态导览员：它同时接收当前全景和对应原著，只能基于白名单展签返回画面观察、文化语境、原文引句与不确定性说明。没有 API Key 时，地图、全景、展签、小游戏和奖励仍能完整运行；WebGL 失败时也能切到静态图继续读完证据。

## 为什么值得做

传统文化产品真正难的，不是再做一个问答框，而是让“结论从哪里来”变得可见。这个项目把原著行号、场景热点、三语展签、游戏证据和 AI 提示约束串在同一条体验链上。评委看到的每个关键判断都能回到第二十七回原文，而不是接受一个看起来很确定的生成答案。

## 对应评审维度

- 创意：把 360°空间叙事和可追溯原著证据结合，不把 AI 当百科聊天框。
- 实用：可用于名著导读、文化展陈和跨语言讲解；公开链接无需注册即可体验。
- 完成度：地图入口、4 幕全景、11 条展签、进度、小游戏、奖励和公开手册形成闭环。
- 技术难度：全景节点与热点运行时、三语内容模型、证据门槛、服务端多模态请求、注入防护、限流和 WebGL 回退协同工作。

## 当前边界

作品当前完整开放第二十七回，不宣称覆盖《西游记》全书。地图上的其他节点只展示产品如何扩展。Gemini 是否在线取决于部署环境是否配置服务端 API Key，但这不影响核心体验。
