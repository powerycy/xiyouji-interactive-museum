# AI 内容生产流程

## 1. 原则

AI 是内容生产助理，不是用户端实时讲故事系统。

所有内容必须遵守：

- 原文证据优先
- 不加入影视、漫画、动画或网文改编
- 不扩写成新剧情
- 不把白话解释冒充原文
- 不生成自由问答式用户端内容

## 2. 输入

输入材料：

- Project Gutenberg《西遊記》原文
- 当前章节文本
- 人物、地点、物件候选
- 已确认美术方向

## 3. 章节处理步骤

1. 从原文中切出目标章节
2. 提取候选人物、地点、物件、事件
3. 标记关键原文段落
4. 为每个热点生成展签草稿
5. 为展签生成简体白话解释
6. 分配探索度权重
7. 生成小游戏事件卡和证据卡
8. 生成美术提示词
9. 人工确认
10. 写入章节 JSON

## 4. 人工确认清单

每张展签上线前确认：

- 是否确实来自本章原文
- 繁体原文是否未被改写
- 简体解释是否准确
- 是否混入改编内容
- 探索权重是否合理
- 是否需要进入小游戏证据池

每个视觉提示词确认：

- 是否符合原著描述
- 是否没有复制现有 IP 造型
- 是否符合暗黑东方神魔漫画风
- 是否适合当前 UI 比例和热点布局

## 5. 展签生成提示词模板

```text
你是《西游记》原著内容策展助理。
请只依据给定原文，生成博物馆展签草稿。
不得加入影视、漫画、动画、网文或民间改编。
不得扩写新剧情。

输出字段：
- title
- type: character/object/location/event/detail
- originalTraditional: 保留原文繁体，不改写
- plainSimplified: 用简体中文解释原文含义
- sourceNote: 第几回，相关位置说明
- explorationWeight: 1 到 20
- requiredForGame: true/false

原文：
{{original_excerpt}}
```

## 6. 小游戏卡片生成提示词模板

```text
你是《西游记》原著互动学习设计师。
请只依据给定章节展签，生成“事件时间线还原 + 证据卡匹配”小游戏内容。
游戏文案必须使用简体白话。
每个事件卡必须能对应一个或多个展签证据。

输出：
- eventCards: 事件卡，包含正确顺序
- evidenceCards: 证据卡，包含来源展签 id
- successFeedback: 完成反馈
- mistakeFeedback: 温和提示

展签数据：
{{labels_json}}
```

## 7. 美术提示词生成规则

美术提示词应包含：

- 场景名称
- 原著依据
- 画面主体
- 情绪和氛围
- 色彩
- 光影
- 构图
- 禁止项

禁止项必须包含：

- 不复制《西行纪》
- 不复制任何现有影视、动画、漫画角色造型
- 不出现现代物品
- 不出现低幼卡通风
- 不出现素淡水彩绘本感
