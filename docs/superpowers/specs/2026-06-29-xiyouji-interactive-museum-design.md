# 设计规格：西游记原著还原型互动博物馆

## 1. 目标

构建一个本地运行的《西游记》原著还原型互动博物馆。第一版包含取经大地图、三打白骨精完整 demo、章节探索度、小游戏、预生成静态全景预览、360 全景或动画奖励、徽章和本地策展工作台。

## 2. 产品形态

产品主形态是“可玩的数字原著博物馆”。核心不是改编剧情，而是把原著内容空间化、展签化、互动化。

第一版以“三打白骨精”为教学章节和 demo。大地图展示更多章节节点，但只有该章节完整可玩。

## 3. 核心机制

章节闭环：

1. 大地图进入章节
2. 点击章节场景热点
3. 展开人物、物件、场景、事件展签
4. 阅读关键展签累计探索度
5. 探索度达到 70% 且小游戏所需线索展签都已读完后解锁小游戏
6. 完成小游戏
7. 展示预生成静态全景预览、360 全景或内置动画
8. 点亮徽章
9. 解锁下一个章节预览

## 4. 文本策略

展签使用“繁体原文 + 简体白话解释”。繁体原文来自 Project Gutenberg #23962《西遊記》，不得被改写后冒充原文。

小游戏全部使用简体白话文，不直接考用户文言文阅读。

## 5. 技术方向

建议使用 Next.js + React 开发本地 Web 应用。

主要模块：

- 用户端：大地图、章节探索、展签、探索度、小游戏、奖励、徽章
- 工作台：内容预览、热点预览、展签确认、资源选择
- 本地数据：JSON 内容文件、本地图片/视频/全景资源
- 进度存储：localStorage 或 IndexedDB

## 6. 美术方向

原创暗黑东方神魔漫画风。可以参考《西行纪》的视觉张力，但不得复制角色造型、服饰、构图、分镜或具体画面。

重点是高对比光影、厚重线条、强体块、妖气、佛光、法器、山石和史诗感。

## 7. AI 使用边界

AI 只用于内容生产辅助：

- 从原著抽取候选热点
- 生成白话解释草稿
- 生成小游戏卡片草稿
- 生成美术提示词
- 辅助生成视觉资源

用户端不开放自由 AI 问答，不允许无限生成剧情。

## 8. 开发边界

不做登录，不做云端数据库，不做支付，不做多人互动，不做全书完整内容。
