# 《西游记》沉浸式全景与景深大地图设计规格

日期：2026-07-19
状态：用户已批准（对应对话中的需求复述及“没问题了，改吧”）

## 目标

把首页和白虎岭章节统一成“文化场景是主体、界面是轻薄信息层”的沉浸式数字博物馆。页面不再呈现普通卡片网站、厚重侧栏或旧图像场景链；所有常驻 UI 都以低对比度半透明玻璃、柔和模糊和克制动效悬浮在画面边缘。

## 白虎岭全景

### 主流程

- 保留全屏 360° 拖动、缩放、信息热点和全景场景跳转热点。
- 移除页面上的“图像场景链”入口及旧链路切换，不删除底层旧内容文件。
- WebGL 无法载入时显示静态全景回退和重试提示，不引导进入旧图片链。

### 热点

- 信息热点不显示“阅”等文字，视觉为 18–22 px 的半透明玻璃核心、外圈柔光和缓慢呼吸波纹。
- 场景跳转热点采用同语言的暖朱红/琥珀玻璃核心和方向性微动效，不使用厚重实色按钮。
- 可见核心小而克制，但实际命中区桌面不少于 48 × 48 px、移动端不少于 52 × 52 px。
- 缩放和拖动后热点仍保持正确坐标与命中。除 Photo Sphere Viewer 的 marker 选择事件外，在热点按钮上绑定直接 click 回调，避免缩放/拖动状态导致事件未被插件上报。
- 尊重 `prefers-reduced-motion`，关闭循环呼吸和大幅位移动效。

### 文化说明浮窗

- 浮窗不再切走固定宽度的画面。桌面使用最大 420 px 的悬浮玻璃窗，依据热点横向位置选择左侧或右侧：热点在画面右半区时窗口靠左，反之靠右；窄屏降级为底部浮层。
- 浮窗与视口边缘保留 18–24 px 空隙，不铺满高度；全景在四周持续可见。
- 背景为带暖米白色调的半透明层，使用 `backdrop-filter: blur(...) saturate(...)`、细亮边和低强度阴影。
- 原文、简释、English 保留三层标签；标签、标题、来源和关闭按钮也使用透明层级，不出现大面积实色块。
- 关闭按钮、Escape 和焦点恢复继续可用。

### 常驻 UI

- 标题牌、操作提示、图例、占位场景状态和全景工具栏统一为半透明玻璃样式。
- 画面中心不放常驻面板；标题与导航贴近边缘，并降低不活动状态的对比度。

## 首页景深大地图

- `journey-map-v2.png` 作为全屏主视觉，使用 `object-fit: cover` 和轻量 CSS 景深移动；不新增重型 3D 依赖。
- 顶部导航、地图标题、路线进度、时间节点详情全部是悬浮玻璃层，与白虎岭全景使用同一组颜色、透明度、边框、圆角和模糊参数。
- 地图节点直接悬浮在大图上。可进入的白虎岭节点具有克制的呼吸反馈；锁定节点降低对比度但保持路线感。
- “取经纪程”面板默认缩起为一枚轻量按钮，用户点击后展开节点列表；再次点击或关闭可收起。
- 节点详情只在用户点选时展开，避免首页同时常驻地图、节点列表和多张卡片。
- 移动端地图仍为全屏，可横向裁切主视觉；浮层控制在安全区内，节点列表成为底部玻璃抽屉。

## 内容覆盖审计

- 区分“第二十七回全部原文”“白虎岭当前全景可见场景的原文证据”“已转化为热点的原文”。
- 不以两个热点代表整回内容完整覆盖。
- 生成本地审计文档，列出当前热点、对应原文行、现有 v2 场景/展签以及未进入当前全景的关键叙事段落。
- 页面只呈现与当前全景画面直接相关的精选原著证据；完整章节证据继续保留在内容模型和后续全景节点中。

## 验收标准

- 页面上不出现“图像场景链”按钮或旧链路入口。
- 在 Chrome 中多次放大、缩小和拖动后，信息热点与场景热点均可通过真实鼠标/触控点击。
- 信息热点无文字，视觉透明且有克制动效；减少动态偏好下不循环动画。
- 桌面浮窗可根据热点位置选择左右，移动端为不遮满画面的底部浮层。
- 首页为单张全屏景深地图，节点和时间面板均悬浮、可展开和收起。
- 自动测试、TypeScript、生产构建通过；完成桌面 1280 × 720 和移动端 390 × 844 QA。
