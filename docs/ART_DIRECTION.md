# 美术方向：原创暗黑东方神魔漫画风

## 1. 总体方向

项目美术应呈现原创暗黑东方神魔漫画风。它要有强烈视觉张力、厚重世界观和章节探索感。

参考气质：

- 东方神魔
- 港漫式力量感
- 强光影
- 厚重线条
- 高对比画面
- 山石、妖气、佛光、法器、古代衣饰

不采用：

- 素淡翻书插画
- 低幼国风绘本
- 卡通 Q 版
- 普通网页插图
- 影视剧截图感

## 2. 与《西行纪》的关系

可以参考《西行纪》带来的方向性启发：神魔压迫感、战斗张力、厚重线条、强体块、暗色画面。

但不得复制：

- 角色造型
- 脸型比例
- 服饰细节
- 武器形态
- 分镜构图
- 标志性画面
- 动画或漫画的具体美术资产

本项目必须从《西游记》原著描述出发，做原创视觉演绎。

## 3. 色彩

推荐主色：

- 玄黑
- 青灰
- 暗金
- 赭红
- 土褐
- 冷白佛光

章节色彩建议：

- 白虎岭：玄黑、青灰、枯黄、妖红
- 佛性或法力时刻：暗金、冷白、淡青
- 妖气时刻：灰绿、暗紫、血红

避免整站单一色调。暗色可以作为基底，但需要金、红、青灰等对比。

## 4. 角色原则

角色必须有辨识度，但不能照搬已有 IP。

孙悟空：

- 警觉、敏捷、战斗感强
- 可有金箍棒，但造型原创
- 不做低幼化

唐僧：

- 清瘦、执拗、慈悲与误判并存
- 不做单纯软弱形象

猪八戒：

- 贪嘴、情绪化、挑唆感
- 不做纯搞笑吉祥物

白骨夫人：

- 伪装与危险并存
- 可以有妖气、骨相、幻化感
- 不做现代性感妖女套路

## 5. 场景原则

场景应服务探索热点。

主场景图需要预留可点击区域：

- 人物可点
- 物件可点
- 地点可点
- 事件痕迹可点

画面不能过于拥挤，热点不能和 UI 冲突。

## 6. UI 原则

UI 应像东方神魔博物馆的展陈系统。

推荐：

- 暗色底
- 暗金边线
- 展签式卡片
- 章节徽章
- 地图节点
- 卷轴和石刻质感可以少量使用

避免：

- 大面积仿古花纹堆砌
- 低清纹理
- 过度拟物
- 和场景图抢视觉重心

## 7. 资产一致性

所有核心资产应保持：

- 同一画幅策略
- 同一角色设定
- 同一光影语言
- 同一 UI 边框和徽章语言

开发前必须先生成 2 到 3 张风格测试图，再确定最终资源生成提示词。
