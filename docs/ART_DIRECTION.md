# 美术方向：原著驱动的东方神魔漫画博物馆风

## 1. 总体方向

项目美术应呈现原著驱动的东方神魔漫画博物馆风。它要有强烈视觉张力、厚重世界观和章节探索感，但不能把整本《西游记》统一处理成暗黑风。

每个章节的色调、光影和氛围必须从原著当章描写出发。白虎岭可以偏险峻、阴森、妖气重；花果山、水帘洞、天宫、女儿国、灵山等章节应有各自不同的气质。

参考气质：

- 东方神魔
- 港漫式力量感
- 强光影
- 厚重线条
- 高对比画面
- 山石、妖气、佛光、法器、古代衣饰

不采用：

- 素淡翻书插画
- 低幼国风绘本
- 卡通 Q 版
- 普通网页插图
- 影视剧截图感

## 2. 与《西行纪》的关系

可以参考《西行纪》带来的方向性启发：神魔压迫感、战斗张力、厚重线条、强体块、暗色画面。

但不得复制：

- 角色造型
- 脸型比例
- 服饰细节
- 武器形态
- 分镜构图
- 标志性画面
- 动画或漫画的具体美术资产

本项目必须从《西游记》原著描述出发，做原创视觉演绎。

## 3. 全书基础设定与章节状态

主角形象不能只从某一回提取。孙悟空、唐僧、猪八戒、沙僧、白龙马等核心角色需要先建立“全书基础设定”，再按章节生成状态版本。

角色基础设定应从全书提取：

- 长期身份和称谓
- 外貌特征
- 常用道具和法器
- 性格特征
- 与其他角色的关系
- 关键变化和历史来源

章节状态应从当前章节提取：

- 所在环境
- 衣物状态
- 道具是否在手
- 情绪状态
- 是否战斗、受伤、饥饿、被困、变身、分离
- 与本章事件的关系

正式美术提示词必须由“全书角色基础设定 + 当前章节状态 + 当前场景动作”合成。

## 4. 色彩

色彩必须随章节变化，不设全书统一暗黑主色。

可用色彩：

- 玄黑
- 青灰
- 暗金
- 赭红
- 土褐
- 冷白佛光

章节色彩建议：

- 白虎岭：玄黑、青灰、枯黄、妖红
- 花果山：青绿、金光、水汽、灵石灰
- 天宫：金、白、朱红、玉色
- 女儿国：暖红、粉金、水色、宫廷色
- 灵山：金白、云青、庄严佛光
- 佛性或法力时刻：暗金、冷白、淡青
- 妖气时刻：灰绿、暗紫、血红

避免整站单一色调。暗色可以作为基底，但需要金、红、青灰等对比。

## 5. 角色原则

角色必须有辨识度，但不能照搬已有 IP。

角色设计流程：

1. 读取全书角色基础设定
2. 读取当前章节状态设定
3. 生成当前章节角色图纸
4. 人工检查是否偏离原著
5. 再进入正式资产生成

孙悟空：

- 警觉、敏捷、战斗感强
- 可有金箍棒，但造型原创
- 不做低幼化

唐僧：

- 清瘦、执拗、慈悲与误判并存
- 不做单纯软弱形象

猪八戒：

- 贪嘴、情绪化、挑唆感
- 不做纯搞笑吉祥物

白骨夫人：

- 伪装与危险并存
- 可以有妖气、骨相、幻化感
- 不做现代性感妖女套路
- 第二七回中应体现三次伪装：年轻女子、老妇人、老公公，以及最终粉骷髅本相

## 6. 地图原则

大地图必须从全书原著中抽取路线线索，不允许让 AI 自由编造路线。

地图设计流程：

1. 从全书回目和正文抽取地点
2. 标记取经路线顺序
3. 标记地点对应章节和事件
4. 识别地点类型：国都、山岭、河流、洞府、寺观、天界、佛土
5. 形成地图节点数据
6. 再进行视觉地图生成

地图可以做艺术化空间表达，但节点顺序、地点归属、章节关系必须有原文依据。

## 7. 场景原则

场景应服务探索热点。

主场景图需要预留可点击区域：

- 人物可点
- 物件可点
- 地点可点
- 事件痕迹可点

画面不能过于拥挤，热点不能和 UI 冲突。

## 8. UI 原则

UI 应像东方神魔博物馆的展陈系统。

推荐：

- 暗色底
- 暗金边线
- 展签式卡片
- 章节徽章
- 地图节点
- 卷轴和石刻质感可以少量使用

避免：

- 大面积仿古花纹堆砌
- 低清纹理
- 过度拟物
- 和场景图抢视觉重心

## 9. 资产一致性

所有核心资产应保持：

- 同一画幅策略
- 全书角色基础设定一致
- 章节状态变化清楚
- 同一光影语言
- 同一 UI 边框和徽章语言

开发前必须先生成 2 到 3 张风格测试图，再确定最终资源生成提示词。
