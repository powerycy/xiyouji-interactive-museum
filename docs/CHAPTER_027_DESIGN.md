# 章节设计：第二七回 三打白骨精 Demo

## 1. 原著定位

主源文件：

- `data/raw/xiyouji/project-gutenberg-23962-xiyouji.txt`

对应回目：

- 第二七回　屍魔三戲唐三藏　聖僧恨逐美猴王

本地原文位置：

- 回目约在第 6988 行附近

## 2. Demo 目标

这一章用于验证完整产品闭环：

- 大地图进入章节
- 高完成度场景探索
- 热点展签
- 探索度达到 70% 且小游戏所需线索展签都已读完
- 小游戏
- 静态全景预览、360 全景或动画奖励
- 徽章和下一节点预览

## 3. 章节主场景

场景名称：白虎岭

主场景应表现：

- 山路险峻
- 妖气潜伏
- 师徒行进疲惫
- 孙悟空警觉
- 唐僧与八戒的关系张力
- 白骨精伪装的危险感

视觉不是清淡国风，而是暗黑东方神魔漫画感。

## 4. MVP 热点

人物热点：

- 孙悟空
- 唐僧
- 猪八戒
- 沙僧
- 白骨夫人

物件热点：

- 斋饭/食物
- 行李担
- 金箍棒
- 紧箍咒

场景热点：

- 白虎岭山路
- 妖气区域
- 变化显形处
- 师徒争执处

事件热点：

- 第一次变化
- 第二次变化
- 第三次变化
- 唐僧责怪悟空
- 八戒挑唆
- 逐走悟空

## 5. 展签样式

每个热点至少包含：

- 标题
- 类型
- 第二七回引用
- 繁体原文摘录
- 简体白话解释
- 探索度权重
- 关联小游戏线索

## 6. 探索度建议

总探索度 100%。

建议分配：

- 白骨精三次变化主线：30%
- 孙悟空识破与行动：15%
- 唐僧责怪与紧箍咒：15%
- 八戒挑唆：10%
- 白虎岭场景与妖气设定：10%
- 关键人物展签：10%
- 关键物件展签：5%
- 彩蛋细节：5%

探索度达到 70%（即 >= 70%），且小游戏所需线索展签都已读完后解锁小游戏。

## 7. 小游戏设计

名称：白虎岭真相时间线

玩法：

1. 用户看到空白时间线
2. 用户拖拽事件卡到正确顺序
3. 关键事件需要选择一张线索卡作为证据
4. 系统即时反馈，但不羞辱用户
5. 完成后触发奖励

事件卡示例：

- 白骨精第一次变化，引诱唐僧师徒
- 孙悟空识破妖怪
- 唐僧责怪悟空伤人
- 白骨精第二次变化
- 八戒在旁挑唆
- 白骨精第三次变化
- 唐僧恨逐美猴王

线索卡必须来自已探索展签中的原文证据。

## 8. 章节奖励

奖励形式二选一，MVP 可先做其一：

- 预生成白虎岭静态全景预览图，后续可替换为严格 360 全景
- 预生成内置动画

奖励完成后：

- 点亮“白虎岭”或“三打白骨精”徽章
- 大地图上下一节点解锁为预览状态

## 9. 验收标准

- 用户不读完整繁体原文，也能通过白话展签理解章节主线
- 用户可随时看到原著证据
- 探索度不是虚假的点击计数
- 小游戏能验证事件顺序和关键因果
- 章节完成有强烈视觉奖励
