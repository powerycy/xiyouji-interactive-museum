# 三打白骨精 Demo 核心美术提示词

## 使用原则

这些提示词用于生成 MVP 开发前核心美术资源。生成后应人工筛选，选择风格一致、热点可用、构图适合 UI 的版本。

生成正式资源前必须先读取：

- `content/characters/*.base.json`
- `content/chapters/027/characters/*.state.json`
- `content/map/route-canon.seed.json`

本章可以偏幽险、妖气重，但项目整体不是固定暗黑风。白虎岭的色调来自章节气氛，不应外推到全书。

通用禁止项：

- 不复制《西行纪》或任何现有漫画、动画、影视作品的角色造型
- 不复制现有 IP 的服饰、武器、构图或标志性画面
- 不出现现代物品
- 不使用低幼卡通风
- 不使用素淡水彩绘本风
- 不使用 Q 版人物
