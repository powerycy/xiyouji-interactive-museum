# 第二七回 v2 剧情证据空间资产 QA 清单

## 准入规则

- 本项目是原著博物馆，不是泛西游概念图。每张图必须先对应《西游记》第二七回的具体情节点、原文段落和展签解释，再谈风格。
- 10 张主线图固定存在，顺序与 `scene-assets.v2.manifest.json` 一致。
- `scene-assets.v2.manifest.json` 每个条目必须填写 `sourceEvidence`：关联展签、原文行号、原文摘录和图像 brief。没有 `sourceEvidence` 或无法回扣原文的候选图不得进入 runtime。
- 每张主视觉最低 1600x900，推荐 1920x1080。
- 每张图必须是独立构图，不能复用 `baihuling-main-v2.png` 或 rejected drafts。
- 每张图必须有清晰可点击证据区域。
- 戏剧张力来自物证、剪影、空间、道路、妖气、尸骨、贬书，不依赖生成正脸表情。
- 场景主视觉默认不得烘焙可读文字；只有原著明确写成“物证文字”的地方可以表现为画面细节，例如 `label-027-final-kill` 的脊梁题名“白骨夫人”。这类文字必须用原文/繁体形态，做成克制的骨上痕迹或题名细节，不得变成大标题、现代标签或 UI 字。
- 场景图片中的所有可读文字都必须是繁体/原文形态，包括脊梁题名、贬书、碑刻、牌额、书信和物件题名；简体中文、伪字、乱码、现代广告字或无关 UI 字一律不通过 QA。
- 画面中的物证文字必须绑定热点：点击脊梁/题名区域先出现轻量说明浮层，再展开完整展签，显示繁体原文、简体白话解释和来源行号。
- 所有文案必须从场景热点进入：每条展签、原文、白话解释和物证说明都要有对应热点，不允许只在后台数据、右侧列表或图片文字里存在。
- 出现孙悟空、唐僧、猪八戒、沙僧时，必须继承 `public/assets/chapters/027/characters/*-v1.png`、`content/characters/*.base.json` 和 `content/chapters/027/characters/*.state.json`。
- 角色不能只满足“看起来像西游”：孙悟空必须保留猴相、紧箍、行者衣装、金箍棒；唐僧必须保留袈裟、毘卢帽、九环锡杖和圣僧威仪，可有法相庄严感，但不能变成世俗帝王或武将；猪八戒必须有黑胖、长嘴大耳、鬃毛、九齿钉钯或行李担的猪怪相；沙僧必须保留蓝靛脸、红发、降妖宝杖、九骷髅前史或行李职责的识别点，不能被改成普通光头和尚；白龙马必须是马形。
- 场景不能错位合并：粉骷髅现形、八戒挑唆、老妇寻女、老公公寻亲、贬书逐猴王必须各自对应原著时刻，不能把后续情节提前画进当前 scene。
- 未通过 QA 的图片只能进入 `docs/review/`，不能进入 `public/assets` + `/chapters/027/scenes/v2/`。

## 单图检查

| 项 | 通过标准 |
| --- | --- |
| 文件名 | 与固定 scene 文件名完全一致 |
| 尺寸 | 宽 >= 1600，高 >= 900 |
| 构图 | 证据空间优先，不是人物漫画表情特写 |
| 可点击区 | 至少 1 个主推进热点，至少 1 个展签/证据热点 |
| 角色一致性 | 若出现角色，不偏离已审核图纸 |
| 原著证据 | 能对应本场景关联展签与原文段落，且不混入前后情节 |
| manifest 证据 | `sourceEvidence.labelIds` 全部存在，`originalExcerpt` 来自第二七回原文，`imageBrief` 明确物证和空间关系 |
| 图片文字 | 默认无可读文字；原著明确的物证文字可出现，但必须是繁体/原文、局部细节、非 UI 标签，并绑定展签热点；任何可读文字不得出现简体、伪字或乱码 |
| 文案覆盖 | 关联展签和物证说明都能从本场景热点打开；不存在孤儿展签 |
| 场景关系 | 人物位置、动作、道具和情绪必须符合该原文时刻 |
| 运行时准入 | 全部通过后才设为 `approved` 并写入 `runtimeSrc` |

## 10 场景焦点

1. `scene-027-01-baihuling-road`：山路、钵盂/行李、无村店空路。
2. `scene-027-02-demon-motive`：阴风、远路、白骨洞影。
3. `scene-027-03-first-disguise`：青砂罐、绿磁瓶、女子剪影。
4. `scene-027-04-wukong-returns`：火眼金睛轮廓、棒影、变质食物。
5. `scene-027-05-bajie-instigation`：坏饭食、钉钯轮廓、锡杖旁摇摆构图。
6. `scene-027-06-second-disguise`：竹杖、老妇背影、哭声路径。
7. `scene-027-07-third-disguise`：老公公背影、包袱、骨影、收紧山路。
8. `scene-027-08-skeleton-reveal`：粉骷髅、散开妖气、金箍棒影；脊梁上可有克制的繁体题名“白骨夫人”作为原著物证；师徒仍在现场，悟空解释本相，不能画成悟空已经离队。
9. `scene-027-09-banish-wukong`：纸笔、贬书、分路、悟空背影/棒影、沙僧行李；只有这一幕可以表现悟空离开。
10. `scene-027-10-chapter-review`：三次伪装证据、粉骷髅、贬书、白虎岭路径。
