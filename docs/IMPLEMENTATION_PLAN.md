# 实施计划

## 阶段 0：准备

目标：

- 确认文档
- 确认美术方向
- 生成 MVP 核心美术资源

任务：

1. 阅读 `docs/README.md`
2. 阅读全部开发前文档
3. 生成 2 到 3 张风格测试图
4. 选择最终美术方向
5. 生成 MVP 核心资源包

验收：

- 大地图风格确定
- 白虎岭主场景可用于热点探索
- 人物图纸和徽章风格一致

## 阶段 1：项目骨架

目标：

- 建立本地 Web 应用
- 搭好页面和数据结构

任务：

1. 初始化 Next.js + TypeScript 项目
2. 建立路由
3. 建立内容 JSON 目录
4. 建立资源目录
5. 建立基础主题样式

验收：

- 应用可本地启动
- `/`、`/chapter/027`、`/studio` 可访问

## 阶段 2：大地图

目标：

- 完成取经大地图和节点状态

任务：

1. 渲染大地图背景
2. 渲染章节节点
3. 支持 locked、preview、available、completed 状态
4. 点击可用节点进入章节
5. 展示徽章状态

验收：

- 三打白骨精节点可进入
- 其他节点显示锁定或预览

## 阶段 3：章节探索

目标：

- 完成白虎岭主场景热点探索

任务：

1. 渲染章节主场景图
2. 渲染热点
3. 点击热点打开展签
4. 展签展示繁体原文和简体白话解释
5. 阅读确认后累计探索度
6. 探索度达到 70% 且小游戏所需线索展签都已读完后显示小游戏入口

验收：

- 热点位置准确
- 展签可读
- 探索度计算正确

## 阶段 4：小游戏

目标：

- 完成“事件时间线还原 + 原文线索卡匹配”

任务：

1. 建立事件时间线 UI
2. 建立事件卡拖拽排序
3. 建立证据卡选择
4. 建立正确性校验
5. 建立成功反馈

验收：

- 事件顺序错误时可提示
- 正确完成后进入奖励页

## 阶段 5：奖励和进度

目标：

- 完成静态全景预览、360/动画奖励、徽章和本地保存

任务：

1. 展示预生成静态全景预览、360 图或动画
2. 点亮章节徽章
3. 保存本地进度
4. 刷新页面后恢复进度
5. 解锁下一节点预览

验收：

- 章节完成状态可持续保存
- 大地图状态更新正确

## 阶段 6：本地工作台

目标：

- 方便内容和美术预览

任务：

1. `/studio` 展示章节列表
2. 预览章节场景和热点
3. 预览展签
4. 检查探索度权重
5. 预览小游戏数据
6. 预览奖励资源

验收：

- 不改代码也能直观看到当前内容结构
- 能发现热点、展签、资源绑定问题

## 阶段 7：打磨

目标：

- 提升完整体验质量

任务：

1. 视觉细节打磨
2. 响应式检查
3. 动效打磨
4. 文案校对
5. 内容证据检查
6. 本地运行文档

验收：

- 桌面端体验完整
- 无明显错位、遮挡、空白资源
- 内容不偏离原著
