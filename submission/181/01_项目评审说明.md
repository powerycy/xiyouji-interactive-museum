# 项目评审说明

## 一句话介绍

《西游记》互动博物馆把原著第二十七回“三打白骨精”转化为可拖拽、可探索、可跳转的多语言 360° Web 文化导览，让中文读者和海外用户通过场景、人物、物件与原文证据重新理解经典故事。

## 要解决的问题

海外用户通常从影视片段或角色标签认识《西游记》，难以接触原著语境；中文读者也常知道剧情却不了解关键原文和人物误解的形成过程。本项目把“阅读古典文本”改造成“在场景里发现证据”：热点先提供可理解的导览，再允许用户回到原文。

## 当前完成度

- 4 个白虎岭 360° 全景场景：山路、送斋女子、连环变化、本相与贬书
- 11 个经人工校对的热点，每个热点包含繁体中文原文、简体中文解释和英文导览
- 场景间热点跳转、拖拽、缩放、静态回退与移动端响应式交互
- 取经路线地图、探索进度、事件排序小游戏和章节奖励闭环
- 56 项自动化测试、TypeScript 检查与 Next.js 生产构建通过

## 推荐体验路径（约 3–5 分钟）

1. 首页取经路线地图点击“白虎岭”。
2. 在第一个全景拖拽视角，点击“白虎岭险路”和“钵盂与饥饿”。
3. 点击跳转热点进入“送斋女子”，切换繁体、简体和英文三种信息。
4. 继续进入“连环变化”和“本相与贬书”，观察同一冲突如何逐步升级。
5. 返回章节完成线索探索与时间线小游戏，查看章节奖励。

## 评审维度对应

### 完成度与表达

项目已有完整可运行的首页—章节—探索—小游戏—奖励闭环，并为桌面与移动端分别设计信息面板。全景资源失败时提供静态图回退，避免评审环境因 WebGL 导致无法体验。

### 创新与 Vibe Coding

核心创新不是把文本做成普通电子书，而是把“原著证据”绑定到空间热点。四个场景既是叙事章节，也是信息架构；用户通过移动视角和选择热点主动组织故事线索。

### Tech for Good

项目使用数字策展降低古典文学的阅读门槛，并将原著、解释与英文导览并置，帮助用户区分“文本证据”和“现代改编印象”。

### 跨文化与本地化

繁体中文保留原著表达，简体中文负责解释难词和语境，英文导览不做逐字直译，而是解释人物关系、叙事功能和文化背景。三层信息可在同一热点内切换。

### Google AI / Google 工具

当前提交版本没有接入 Google AI 或 Gemini API，材料不会把未完成的能力申报为已实现功能。后续可将 Gemini 用于受原著证据约束的多语言导览草稿、问答和内容审核，但该部分不计入本次已完成功能。

## 技术实现

- Next.js + React + TypeScript
- Photo Sphere Viewer：equirectangular 全景、热点、虚拟场景跳转
- 本地 JSON：章节、展签、原著行号和三语内容
- localStorage：探索和奖励进度
- Vitest + Testing Library：内容结构和交互回归测试

## 当前边界

本次样板聚焦《西游记》第二十七回，尚未把全部章节制作成全景；没有实时 AI 生成；没有服务器端账户体系。这个边界保证评委看到的每一项能力都可实际运行和核验。
