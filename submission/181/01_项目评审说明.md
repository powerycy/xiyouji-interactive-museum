# 项目评审说明

## 一句话介绍

《西游记》互动博物馆把原著第二十七回“三打白骨精”转化为可拖拽、可探索、可跳转的多语言 360° Web 文化导览，并用 Gemini 3.5 Flash 同时阅读场景画面与原著证据，为不同文化背景的访客提供可追溯的 AI 策展解读。

## 要解决的问题

海外用户通常从影视片段或角色标签认识《西游记》，难以接触原著语境；中文读者也常知道剧情却不了解关键原文和人物误解的形成过程。本项目把“阅读古典文本”改造成“在场景里发现证据”：热点先提供可理解的导览，再允许用户回到原文，并可继续追问 Gemini。

## 当前完成度

- 4 个白虎岭 360° 全景场景：山路、送斋女子、连环变化、本相与贬书
- 11 个经人工校对的热点，每个热点包含繁体原文、简体解释、英文导览和原文行号
- Gemini 3.5 Flash 多模态文化导览：全景图 + 原著证据 + 访客问题联合解读
- 场景热点跳转、拖拽、缩放、静态回退与移动端响应式交互
- 取经路线地图、探索进度、事件排序小游戏和章节奖励闭环
- 63 项自动化测试、TypeScript 检查与 Next.js 生产构建通过

## 推荐体验路径（约 3–5 分钟）

1. 首页取经路线地图点击“白虎岭”。
2. 在第一个全景拖拽视角，点击白色文化热点。
3. 切换繁体、简体与 English，并向 Gemini 提问：“白虎岭的地形在故事里起到什么作用？”
4. 观察 Gemini 返回的画面观察、文化语境、原文引句和置信边界。
5. 沿红色场景入口继续探索，完成时间线小游戏并查看章节奖励。

## 评审维度对应

### 完成度与表达｜25%

项目已有完整可运行的“地图—全景—展签—AI 问答—小游戏—奖励”闭环，并提供桌面、移动端和 WebGL 静态回退。代码、Demo 说明、Prompt、生成过程、演示视频和合规声明均可核验。

### Google AI / Google 工具｜25%

项目通过官方 Google Gen AI SDK `@google/genai` 接入 Gemini 3.5 Flash。服务端把当前全景图、人工校对的原著段落、三语策展文本和访客问题组成多模态输入；模型以结构化 JSON 返回“回答、画面观察、文化语境、原文引句、置信边界”。API Key 仅在服务端读取，内容 ID 与图像路径由白名单模型解析，访客问题被明确视为不可信文本。

### 创新与 Vibe Coding｜20%

创新不是把文本做成普通电子书，而是让“原著证据—空间热点—AI 解释”形成闭环。Gemini 不做脱离来源的泛聊，而是在当前场景与特定原文范围内工作，把可见事实、文本证据和解释分层呈现。

### Tech for Good｜20%

项目用数字策展降低古典文学门槛，帮助用户区分“原著文本”和“现代改编印象”。证据行号、AI 置信边界和人工校对机制也提供了一种更负责任的文化遗产 AI 使用方式。

### 跨文化与本地化｜10%

繁体中文保留原著表达，简体中文解释难词与语境，英文导览面向国际访客解释人物关系和叙事功能。Gemini 会跟随当前语言输出，并被提示避免异域化和文化刻板印象。

## 技术实现

- Next.js + React + TypeScript
- Photo Sphere Viewer：equirectangular 全景、热点、虚拟场景跳转
- Google Gen AI SDK + Gemini 3.5 Flash：图像与原著联合解读、结构化输出
- 本地结构化内容模型：章节、展签、三语文本和原著行号
- localStorage：探索与奖励进度
- Vitest + Testing Library：内容、交互、API 与安全边界回归测试

## 当前边界

本次样板聚焦《西游记》第二十七回，尚未把全部一百回制作成全景；Gemini 运行需要评审环境配置 API Key。未配置 Key 时，其余博物馆体验仍可完整运行。材料中的旧版 PPT 图片均标注为“早期概念视觉”，不会冒充当前实机效果。
